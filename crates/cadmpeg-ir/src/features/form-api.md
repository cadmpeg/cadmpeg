# Form constructions

`FormConstruction` owns native inputs, canonical cage observations, and one current membership. `default()` creates unknown membership. `complete()` admits an ordered list of distinct subdivision cage IDs. `try_new()` checks explicit inputs, indices, positions, resource states, and membership claims. Deserialization applies the same checks.

## Inputs

`FormInputs.parameters` preserves the native parameter expression map. `references` is the ordered direct-reference run, including repetitions. `reference_runs` retains incompatible direct-reference runs when a single order is unresolved. Each `FormNativeList` records its `source` path, `role`, declared count, and readable `FormNativeMember` values. A member's zero-based `ordinal` is its source slot; `reference` is its native record ID. `CageObjects`, `TrackingSelection`, and `CageCatalog` name their respective source lanes. `CageCatalogCompanions` records the companion lane independently. `TrackingSelectionFixedAssumed` records the alternative fixed-slot reading of a sparse tracking run.

## Reference evidence

A `FormNativeReference` gives the source record, role, zero-based ordinal, optional group label, optional inline type GUID, target, and optional serializer resource. References with the same source, role, and present group belong to one alternative. Group labels distinguish alternatives within a source and role and carry no source order. A consistent relabeling preserves the represented groups. An absent group leaves the claim ungrouped. Body ordinals 0 through 3 identify the owner, body container, cage surface, and scene node. Serializer surface references use ordinal zero. Tracking owner and member references use their source and ordinal. `TrackingMemberFixedAssumed` is the fixed-slot alternative to `TrackingMember`.

`Local` targets contain a typed native ID. `Segment` targets contain the native entity and segment numbers and retain an optional asset GUID when the qualified same-document spelling supplied it. `Document` targets contain the entity, segment, literal asset GUID, optional separately encoded target type GUID, literal link name, and optional version. The inline type and separate type can both be present and can conflict. At least one type claim is present for a document target. `Null` is an explicit one-byte absence, `Unreadable` is a failed slot read, and `Unvisited` is a subsequent slot whose boundary could not be established. These variants retain the same source, role, group, and ordinal as a readable reference.

## Observations and membership

A `FormCageObservation` contains independently established native paths and one binding. `Decoded` names a cage and can name its source resource. `Undecoded` retains a resource and its availability. `Unresolved` retains a path without a resource or cage join. A resource pairs a typed source ID with literal archive-entry text. `ActiveUndecoded` means the active entry is present without a neutral cage. `Inactive` means the known active folder lacks the entry. `Unknown` means the active folder is unavailable. `Ambiguous` means evidence does not establish one compatible current resource state or association. `resource_evidence` retains resource identities and `resource_state_evidence` retains conflicting inventory claims.

`resource_associations` retains additional or displaced cage-to-resource facts, keyed by decoded cage identity. A pair is distinct from the cage's primary binding and every other pair. The association records the source fact independently of current membership and resource availability. `cage_resource_conflicts` checks associated entries for inactive or ambiguous states and associations with other decoded cages.

`FormMembership::Complete` selects an ordered vector of distinct decoded observations. Its `order` states whether order comes from source data or an assumption. Its `certainty` separately states whether membership itself comes from source data or an assumption. `FormMembership::Partial` retains an optional cardinality, an order claim or `Unknown`, and confirmed `FormMember` values. A member's observation index addresses the canonical observation vector. A missing ordinal means that the member is established but its position is unknown. Nonselected decoded observations are candidates. `committed_cages()` returns decoded selected members; `referenced_cages()` includes candidates. A known empty complete construction remains distinct from unknown membership.

`position_evidence` preserves an observation, ordinal, and optional source path. `order_evidence` preserves a source or assumed relative sequence of two or more canonical observation indices, including sequences whose absolute ordinals are unknown. A repeated index records conflicting source slots that later resolved to one observation; it cannot describe a current known order. `cardinality_evidence` preserves independent counts. `closure_evidence` preserves the member sequence, order, and certainty of an earlier complete membership when conflicting evidence makes the current membership partial. Complete membership agrees with every count, closure, position, and relative-order claim. A complete membership cannot select a cage whose associated entry is inactive, ambiguous, or associated with another decoded cage. Incompatible claims remain evidence in a partial construction. An inactive resource cannot be a current selected binding.

## Wire and identities

Complete cage arrays contain distinct values. When `cage_inputs` is present, the array agrees with its selected decoded observations. The generated schema enforces the expressible uniqueness and GUID constraints. The constructor and deserializer enforce cross-field agreement, valid indices, positions, resource states, and type-claim presence.

Identity rewriting visits typed native and subdivision IDs, including absent native endpoints. Parameter, archive-entry, asset, type, link, and version text remains literal even when it equals an identity replacement key.
