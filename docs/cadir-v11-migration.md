# CADIR v11: migration from the branch types

`docs/cadir-v11.md` states the v11 wire. This note maps the v10 types to their v11 form for the codec ports that move a decoder or writer from one to the other. It is not part of the specification: where the two differ, the specification holds. The section numbers are the specification's.

| Branch | v11 |
|---|--- |
| model arenas at the top level of `Model` | `CadIr.geometry: Topology`; the other model arenas in `model` |

The branch operation `Compound` is a `Combine` with `BooleanOp::Compound` (§6.5). `ReverseShape` is an `Extract` with `reversed` (§6.5). `Decal` is §6.4's `Decal`, which states its `placement`; the branch's `DecalMapping` has no counterpart, since every stored decal's image lies on the faces by distance from its frame's origin, which the placement states, and follows no face's parameter domain as the branch's `FitToFaces` does (§6.4), and `Flex` is §6.5's `Flex`, its `FlexMode` the `FlexKind`; `RefineShape` is a definition's `refine` (§5.10); `ReferenceImage` is presentation.
