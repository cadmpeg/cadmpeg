# Codec integration-test partitions

The integration suites use generated byte images that cover container variants
and feature combinations. No source payload is embedded or copied into the
repository.

Each suite has seven partitions. A partition enters through detection, inspection, `Codec::decode`, preserved-source writing, or source-less writing and checks neutral IR, native namespace, source accounting, and validation where the format supports those stages.

## Shared pipeline

The input pipeline is format detection, bounded container framing, logical stream classification, native record parsing, native-reference resolution, neutral geometry/topology projection, design/product/presentation projection, loss and byte-accounting finalization, and IR validation. Preserved-source writers add semantic diffing and native record patching. Source-less writers add target validation and native serialization.

## CATIA CATPart

Scope: compound-document framing; nested V5, FBB-only, zero-entity, E5, A8/B5 float-packed, and container-only variants; radial topology; analytic and NURBS carriers; parametric supports; object/design data; source accounting.

Partitions: standard detection/inspection/decode alignment; standard radial graph; FBB-only transfer; zero-entity support; coherent E5 precedence; float-packed A8 grid; all-variant container-only retention.

## Creo PRT

Scope: PSB framing and ND section layouts; visible-geometry tables; analytic/freeform carriers; intersection topology; datum and model-status history; FeatDefs sketches, dimensions, relations, solver tables, and feature semantics; preview and opaque retention.

Partitions: PSB roles; analytic prototype placement; closed plane-intersection solid; datum/history merge; mixed sketch entities and native constraints; solver incidences and relation triples; geometry/design/thumbnail container-only retention.

## Autodesk Fusion F3D/F3Z

Scope: ZIP and nested ZIP framing; ASM BinaryFile record streams and history partitions; analytic, NURBS, pcurve, and procedural geometry; Protein properties; design streams, sketches, materials, configurations, and history; external F3Z occurrence graphs; retained and source-less writing.

Partitions: F3D container and B-rep pipeline; geometry-family matrix; Protein/design/history/configuration correlation; preserved semantic geometry edits; source-less writer; recursive F3Z occurrence merge and cycle recovery; container-only native retention.

## FreeCAD FCStd

Partitions: ZIP layout matrix; typed graph build/mutate/write; exact geometry/topology/pcurve/mesh/placement composition; sketch/conic/NURBS/constraint composition; feature-family composition; product/application/GUI/drawing composition; atomic refusal and container-only retention.
