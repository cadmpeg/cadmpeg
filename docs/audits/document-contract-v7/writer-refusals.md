# Writer refusal-site audit

This audit records the original writer decisions and their required outcome under the document contract. Historical site coordinates refer to `main` at `7bcc9527`; later source movement does not change the recorded site. New shared policy checks and admission paths are marked `new`. Internal `UnsupportedContent` signals are control flow: the public plan catches them and produces a synthesized plan with export losses. They are not terminal writer refusals.

| Class | Required outcome |
|---|---|
| P | A patch cannot express the edit. Synthesize from typed document content and report `PatchDeclined`. |
| S-arena | The target cannot hold an arena. Mark it Dropped and report a loss. |
| S-entity | Use a solved carrier or omit the unsupported entity. Omit its containing body only when structural validity requires it. Charge Error for structural degradation. |
| C | Refuse malformed or inconsistent document content. |
| O-capacity | Refuse content that exceeds checked format field or count capacity. |
| O-target | Refuse an unresolved target. |
| Precondition: unrepresented | A patch or replay cannot consume source-only content. Select synthesis where available; never admit that source content through retained bytes. |

Arena-wide unsupported content does not refuse the document. Empty output is a valid synthesized file with the `NoExportableSolids` taxonomy loss and the existing caller `--allow-empty` policy. Neutral arenas control any conflicting native counterpart. Retained bytes may select layout and identities but cannot supply content.
