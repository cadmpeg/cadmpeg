# Native-arena disposition (concluded audit)

This audit is concluded. Every listed native arena is retained. A native
arena is retained when it carries source meaning, a byte-preservation
contract, a reference needed to interpret another arena, or evidence used
by a supported command. A derived arena is also retained when deleting it
would make the native namespace less auditable.

The rows below are namespace dispositions. Each arena named in an `Arenas`
cell has the contract, reference, command, fidelity, and decision stated for
that row. The manifests are the codec arena manifests and the arenas loaded by
the codec native validators. Empty arenas are not a reason to delete the
schema.

## Disposition totals

The audit recorded six grouped namespace dispositions: **retain 6, migrate 0,
remove 0**. No arena is marked for removal. A later removal requires a new
audit, a namespace-version change, and an explicit old-reader migration rule.

The `iges` row was added after the audit concluded and applies the same
criteria. The recorded audit total stays six.

The absence of a writer or of `validate_native` was treated as evidence about
consumers, not as a cull rule. The decision is preservation of the current
native contracts and their versioned readers.
