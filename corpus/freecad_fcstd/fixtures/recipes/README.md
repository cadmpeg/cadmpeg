# Revolution fixtures

These files are CC0 CAD Fixture Recipes files from the local public recipe set.
The names contain the producer version and recipe id.

F06b: rectangle x=20..30, z=0..40, revolved 270 degrees about Z.
F15b: the same rectangle, 90 degrees on the first side and 45 on the second.
F15c: the same rectangle, a symmetric total sweep of 180 degrees.

Source: cad-fixture-recipes-creo/generated/freecad-<version>/<recipe>.FCStd.
